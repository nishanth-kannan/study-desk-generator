# Study Desk Generator

A Claude skill that turns course material into **one offline HTML revision desk**: past papers digitized
word for word with their official solutions, a generated question bank, concept notes and a quick
reference. Progress is saved in the browser. Built for MBA-style courses with lots of quantitative work,
so every numeric solution comes with its Excel formulae.

## How it works

Scripts do everything mechanical; Claude does the reading, judging and writing.

```
uploads ─► ingest.py ─► sources/<id>.txt   verbatim master text (typed PDFs via pdfplumber, scans via Tesseract)
                        work/summary.txt   what needs eyes: table/figure crops, OCR review strips, nothing else
        ─► scaffold.py ─► data/papers/*.json   every question, table, figure and official solution, copied verbatim
        ─► Claude ─────► explanations, calc blocks, concept notes, question bank, OCR fixes
        ─► build_desk.py ─► checks · Excel recalculation · compare sheet · the desk (.html) + workings (.xlsx)
        ─► verify.py ────► headless smoke test
```

What the build refuses to ship:

| Check | Catches |
|---|---|
| precision | paraphrased or invented wording |
| recall | a dropped word, sentence, sub-part or whole question |
| numbers (multiset) | a changed digit (459 for 450), in text, options or tables |
| objects | a table or figure in the paper that isn't shown |
| official solutions | the same three checks against the solution sheet |
| calc | Excel workings recalculated in LibreOffice that disagree with the key or the correct option |
| `_check` | a guess the scaffold made that nobody confirmed |

`work/compare.html` puts each original crop beside its digitized version, riskiest first, so a human
can check the digitization in minutes.

## Install

- **Claude (web, desktop)**: download `study-desk.zip` from the [latest release](../../releases/latest)
  and upload it under Settings → Capabilities → Skills.
- **Only the SKILL.md installed?** It still works: the first build step clones the matching release
  of this repo for the scripts.

Then ask Claude for a study desk and attach the papers, solutions and readings.

## Repository layout

```
study-desk/              the installable skill (this folder is what the release zip contains)
  SKILL.md               instructions Claude follows
  scripts/               ingest, scaffold, build_desk, checks, calc, compare, verify, check_env, template
    VERSION
tests/                   synthetic fixtures, scripted "Claude" edits, fault injection, OCR evaluation
.github/workflows/       release: test, then attach study-desk.zip to the GitHub release
```

## Releasing a new version

1. Change the scripts and/or `SKILL.md`; run `tests/run.sh` (needs poppler, tesseract, LibreOffice, Playwright).
2. Bump `study-desk/scripts/VERSION` and both `v2.0` references in `SKILL.md` (`--branch` and `--expect`) to the new tag.
3. Commit, then `git tag v2.1 && git push --tags`. The workflow refuses a tag that disagrees with
   `VERSION` or `SKILL.md`, runs the tests, and publishes `study-desk.zip`.

Protect `v*` tags in the repository settings (Rules → Rulesets) so a published release can't be moved.

## Test material

The tests use synthetic papers generated by `tests/make_fixtures.py` (a typed paper, a degraded scan, a
typed solution sheet and a handwritten-style one). **Never commit real exam papers or solutions** —
they are usually not yours to publish.
